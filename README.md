# ⚡ BEOMCHRO (범크로) v2.1
> **NOL 티켓 & 인터파크 티켓 게이트 0ms 대기열 진입 엔진 & 무설치 올인원 프로그램**  
> *Nol-Ticket & Interpark Gate Ultra Fast 0ms Queue Interceptor Engine (Zero-Python & Zero-Setup App)*

---

## 1. 프로젝트 개요

**BEOMCHRO (범크로) v2.1**은 대규모 티켓팅 오픈 정각(00.000초) 시 인간의 신체적 반응 속도 한계(300~400ms)를 극복하고, **0~1ms 미만**으로 대기열 진입 버튼을 가로채 최선두 대기 순번(1번 대기)을 선점하기 위한 크로스 플랫폼 자동화 시스템입니다.

### 🌟 v2.1 핵심 업데이트 & 사용자 피드백 반영
1. **🪟 윈도우 파이썬(Python) 미설치 PC 100% 즉시 작동 (`Zero-Python`)**:
   - 윈도우 컴퓨터에 파이썬이 깔려 있지 않아도, `run_windows.bat`을 더블클릭하면 **윈도우 기본 내장 엔진(`beomchro_win_native.ps1`)**이 자동 가동되어 별도 프로그램 설치 없이 즉시 실행됩니다.
   - GitHub Actions 워크플로(`.github/workflows/build_windows_exe.yml`)를 통해 독립 실행형 `BEOMCHRO_Windows_Portable.zip` (`BEOMCHRO.exe`) 자동 빌드를 지원합니다.
2. **🟢 실시간 `[🟢 ON (작동중) / ⚪ OFF (정지됨)]` 스위치 & `[🔍 작동확인]` 버튼 탑재**:
   - 브라우저 우측 상단 컨트롤 위젯에서 언제든 클릭 한 번으로 감시 엔진을 **ON / OFF** 할 수 있습니다.
   - **`[🔍 작동확인]`** 버튼을 누르면 현재 화면에서 조준된 예매 버튼(`남은시간 XX:XX` 또는 `예매하기`)에 **파란색 네온 레이저 테두리**를 비춰주어 정상 작동 여부를 즉시 눈으로 확인할 수 있습니다.
3. **✋ 정각(00:00) 행동 요령 완벽 안내 (손 떼고 대기!)**:
   - **정각에 직접 마우스를 클릭하거나 마우스 커서를 버튼 위에 올려두실 필요가 전혀 없습니다!**
   - `[🟢 ON (작동중)]` 상태로 페이지만 열어 두시면, 카운트다운이 끝나고 버튼이 활성화(`disabled` 해제)되는 0.0001초 찰나에 브라우저 내부 엔진이 **자동으로 0ms 클릭**을 수행합니다.
4. **⚾ 실제 사이트 100% 복제 내장 연습장 (`2026 한국시리즈 7차전 KT vs 삼성` & `NOL 티켓 한국시리즈 목록`)**:
   - 실제 인터파크 티켓 게이트(`tickets.interpark.com/gates/ticket/*`)와 NOL 티켓 포스트시즌 페이지(`nol.yanolja.com/ticket/genre/sports/postseason`)의 실제 HTML/CSS 클래스 구조를 그대로 내장하여, 실전과 100% 동일한 환경에서 5초/10초 카운트다운 및 0ms 자동 격발을 검증할 수 있습니다.
5. **📘 공식 올컬러 비주얼 사용 설명서 PDF**:
   - [`BEOMCHRO_사용설명서.pdf`](BEOMCHRO_사용설명서.pdf) (순서도, ON/OFF 조작법, 정각 행동 요령, 한국시리즈 연습장 가이드 수록)

## 2. 자주 묻는 핵심 질문 2가지 (필독!)

| 질문 | 명쾌한 해답 |
| :--- | :--- |
| **Q1. 숫자 `1`을 눌렀는데 파란불만 들어오고 작동 중인지 모르겠어요! ON/OFF가 있나요?** | 브라우저 우측 상단 컨트롤 박스에 **`[🟢 ON (작동중)]` / `[⚪ OFF (정지됨)]` 토글 스위치**와 **`[🔍 작동확인]`** 버튼이 있습니다. 또한 조준된 예매 버튼 둘레에 **파란색 네온 테두리**가 표시되며, 컨트롤 박스에 `🎯 타겟 조준 완료: [남은시간 39:01]`처럼 실시간 버튼 상태가 표시됩니다. |
| **Q2. 정각(00:00)에 제가 직접 누르는 건가요, 아니면 마우스 커서만 갖다 두는 건가요?** | **둘 다 아닙니다! 마우스에서 아예 손을 떼고 계세요.** 마우스 커서를 버튼 위에 올려두실 필요도 없고, 직접 클릭하실 필요도 없습니다. `[🟢 ON (작동중)]` 상태만 유지하면 정각에 버튼이 열리는 순간 프로그램이 자동으로 0ms 클릭합니다. (직접 클릭 시 중복 요청으로 대기열이 튕길 수 있으니 손대지 마세요!) |

## 3. 빠른 시작 가이드 (Quick Start)

### 🍎 macOS 사용자 (더블클릭 원클릭 실행)
1. 프로젝트 폴더의 **`BEOMCHRO.app`** (또는 **`BEOMCHRO.command`**)을 **더블클릭**합니다.
2. 대시보드가 열리면 숫자 **`1`**을 입력하고 엔터를 누릅니다.
3. 전용 브라우저가 열리며 **`2026 한국시리즈 7차전 KT vs 삼성` 내장 연습장**과 **실제 NOL 티켓 페이지**가 함께 열립니다.
4. 연습장 상단의 **`[⏱️ 5초 카운트다운]`**을 누르고 마우스에서 손을 떼면, 5초 뒤 `0ms` 자동 격발과 함께 **대기 순번 1번** 팝업이 뜨는 것을 바로 확인할 수 있습니다.

### 🪟 Windows 사용자 (파이썬 설치 불필요!)
1. 프로젝트 폴더의 **`run_windows.bat`**를 **더블클릭**합니다.
   - PC에 파이썬이 없어도 윈도우 기본 내장 엔진(`beomchro_win_native.ps1`)이 자동 실행됩니다.
2. 대시보드에서 숫자 **`1`**을 입력하고 엔터를 누르면 0ms 엔진이 장착된 크롬/엣지/웨일 브라우저와 내장 연습장이 즉시 실행됩니다.

## 4. 디렉터리 및 파일 구조

```text
beomchro/
├── BEOMCHRO.app/                  # macOS 네이티브 더블클릭 애플리케이션 번들
├── BEOMCHRO.command               # macOS 더블클릭 실행 스크립트
├── BEOMCHRO_사용설명서.pdf         # 5페이지 올컬러 비주얼 사용 설명서 (순서도/다이어그램 포함)
│
├── run_windows.bat                # Windows 무설치 원클릭 런처 (Python 유무 자동 판별)
├── beomchro_win_native.ps1        # Windows 순수 내장 엔진 (Python 없이 100% 작동)
├── build_windows_exe.py           # Windows 단일 EXE 빌드 스크립트 (PyInstaller)
├── build_windows.bat              # Windows EXE 원클릭 빌드 배치파일
├── .github/workflows/             # GitHub Actions Windows EXE 자동 빌드 워크플로
│
├── extension/                     # 브라우저 무설치 자동 장착 확장프로그램 (Manifest V3)
│   ├── manifest.json              # 놀티켓/인터파크 게이트/로컬 연습장 권한 설정
│   ├── content.js                 # 0ms MutationObserver 엔진 + [ON/OFF] & [작동확인] HUD
│   └── icons/                     # 16, 48, 128px 고해상도 아이콘
│
├── simulator/                     # 실제 사이트 기반 내장 테스트 연습장 (:8989)
│   ├── index.html                 # 2026 한국시리즈 7차전 KT vs 삼성 게이트 & 시리즈 목록
│   ├── style.css                  # 인터파크 게이트(_button_4ncv0_1) & NOL 티켓 실전 스타일
│   └── script.js                  # 카운트다운(남은시간 XX:XX ➔ 예매하기) 및 0ms 검증 엔진
│
├── img/                           # 실제 사이트 참조 원본 HTML/에셋 (한국시리즈 7차전 등)
```
